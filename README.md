# Mon Site Vitrine

Projet realise en equipe dans le cadre du TP "Travail collaboratif avec Git Flow".

## Equipe

- Dev 1 - feature/header
- Dev 2 - feature/hero
- Dev 3 - feature/services
- Dev 4 - feature/footer

## Workflow Git

- `main` : version stable du projet
- `develop` : prochaine version en cours de developpement
- `feature/*` : nouvelles fonctionnalites
- `fix/*` : corrections classiques
- `release/*` : preparation des versions
- `hotfix/*` : corrections urgentes de production

Toute modification de `main` ou `develop` passe obligatoirement par une Pull Request validee par 2 membres.
